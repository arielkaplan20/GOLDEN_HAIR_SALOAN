# GOLDEN HAIR SALON

אתר לניהול תורים במספרת גברים ולמכירת מוצרים הקשורים לשיער.

פרויקט גמר — הנדסאי תוכנה.
מגיש: אריאל יצחק קפלן.

## מה האתר עושה

האתר מאפשר ללקוחות המספרה לנהל את התורים שלהם באופן עצמאי — לקבוע תור, לצפות בתורים
קיימים, לשנות תור ולבטל תור — במקום להתקשר לספר ולתפוס אותו באמצע עבודה. בנוסף יש באתר
חנות שבה אפשר לרכוש מוצרים הקשורים לשיער, כמו מכונות תספורת וג'ל לשיער.

במערכת יש שלושה סוגי משתמשים:

| משתמש | מה הוא יכול לעשות |
|---|---|
| לקוח | הרשמה והתחברות, הזמנת תור, צפייה/שינוי/ביטול תור, רכישה בחנות, עדכון פרופיל |
| נותן שירות (ספר) | צפייה ביומן התורים שנקבעו אליו בלבד, עריכת ימי ושעות העבודה שלו |
| מנהל ראשי | ניהול משתמשים והרשאות, צפייה בכל התורים, ניהול מוצרי החנות וההזמנות |

## טכנולוגיות

- **צד לקוח:** React
- **צד שרת:** Node.js + Express
- **מסד נתונים:** MongoDB
- **שפות:** HTML / CSS / JavaScript
