# תרשימי הספר

בתיקייה `puml/` נמצאים 22 קובצי PlantUML, אחד לכל תרשים בספר.

## מה לעשות

1. היכנס ל-https://www.plantuml.com/plantuml/uml/
2. פתח קובץ `.puml`, העתק את התוכן והדבק באתר
3. לחץ Submit, ואז לחץ על הקישור PNG ושמור את התמונה
4. שמור אותה בתיקייה `png/` **בדיוק באותו שם** של קובץ ה-puml, עם סיומת `.png`

לדוגמה: `01-seq-suc01-הרשמה.puml` נשמר כ-`png/01-seq-suc01-הרשמה.png`

5. כשסיימת, הרץ מהתיקייה הראשית:

```
node scripts/insert-diagrams.js
```

הסקריפט יחליף כל בלוק קוד בספר בתמונה המתאימה.
אפשר להריץ אותו גם אם רק חלק מהתמונות מוכנות - הוא ידלג על מה שחסר.
